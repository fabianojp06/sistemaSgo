Leitura rápida

  • A muda o mínimo — mesma tela, mesma ordem, só recolhe o que não está em uso. Menor risco, menor ganho.
  • B é a mudança mais estrutural — separa "o que eu edito" de "o que eu confiro" (Rubi + custo calculado sempre visíveis). Melhor para quem edita Cargo com frequência.
  • C força uma ordem — bom em cadastro guiado, mas atrapalha quem só quer corrigir um campo no meio.
